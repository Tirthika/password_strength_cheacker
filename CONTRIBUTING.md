# Contributing Guidelines

Thank you for your interest in contributing to Password Strength Checker!

Contributions, bug reports, suggestions, and improvements are welcome.

## Getting Started

1. Fork this repository.
2. Clone your fork:

   ```bash
   git clone https://github.com/YOUR_USERNAME/password_strength_cheacker.git
   ```

3. Create a new branch:

   ```bash
   git checkout -b feature/your-feature-name
   ```

4. Make your changes and test them.
5. Commit your changes:

   ```bash
   git commit -m "Add: describe your changes"
   ```

6. Push your branch and open a Pull Request.

## Contribution Ideas

- Improve password input validation.
- Fix bugs and calculation errors.
- Improve password strength estimation.
- Add test cases.
- Improve documentation.
- Improve code readability and maintainability.

## Code Guidelines

- Write clean and readable C code.
- Use meaningful variable and function names.
- Avoid unnecessary dependencies.
- Handle invalid input safely.
- Test your changes before submitting a Pull Request.

## Pull Request Guidelines

- Explain what your change does.
- Explain why the change is useful.
- Include testing information.
- Keep each Pull Request focused on one improvement.

## Reporting Bugs

Please create a GitHub Issue describing:

- What happened.
- What you expected to happen.
- Steps to reproduce the problem.
- Relevant compiler errors, if any.

Thank you for helping improve this project!
